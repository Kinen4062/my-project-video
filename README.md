# AI 3D 视频播放器

基于深度估计的 2D 转 3D 视频播放器，支持多种 3D 显示模式、实时视差调节、音频同步播放等功能。

> 仓库地址：https://github.com/Kinen4062/my-project-video

---

## 项目简介

本项目是一个实验性的桌面视频播放器，核心目标是将普通 2D 视频实时转换为 3D 效果并播放。播放器使用 AI 深度估计模型（Depth-Anything-V2）为每一帧生成深度图，再通过视差映射合成左右眼画面，最终以红蓝、偏振等格式呈现 3D 效果。

项目从最简单的命令行播放器起步，逐步演进到功能完整的 GUI 应用，记录了整个开发过程。

---

## 功能特性

### 播放核心
- 打开本地视频文件，基于 OpenCV 逐帧读取
- 播放 / 暂停（按钮或空格键）
- 进度条拖动跳转，点击进度条任意位置跳转
- 倍速播放：0.5x / 1.0x / 1.5x / 2.0x
- 循环播放（读到结尾自动回到开头）
- 窗口标题实时显示“当前秒数 / 总秒数”

### 音频
- 使用 ffpyplayer 解码并播放视频原声
- 音量滑块实时调节音量
- 静音按钮一键开关
- 暂停 / 继续时音频同步暂停 / 恢复
- 拖动进度条时音频同步跳转到对应位置
- 关闭窗口时彻底释放音频资源，避免 SDL 线程残留

### AI 2D 转 3D
- 使用 `Depth-Anything-V2-Small-hf` 深度估计模型
- 自动选择 CUDA / CPU 推理
- 逐帧生成深度图，通过 `cv2.remap` 生成左右眼画面
- 输出左右并排（SBS）的 3D 视频
- 后台线程转换，不阻塞界面
- 实时进度显示：已处理帧数 / 总帧数、百分比、预计剩余时间
- 支持取消转换，自动清理写了一半的临时文件
- 转换完成后自动播放，并切换到红蓝 3D 模式

### 3D 显示与调节
- 支持多种 3D 显示模式：
  - **2D** — 原始画面
  - **红蓝 3D** — Anaglyph
  - **偏振-隔行** — 奇数行左眼，偶数行右眼
  - **偏振-隔列** — 奇数列左眼，偶数列右眼
  - **偏振-棋盘** — 棋盘格交错分配
- **实时视差调节**：滑块范围 -15 ~ +15，播放中或暂停时即时生效
- **左右眼交换**：一键切换左右眼，应对眼镜戴反或片源左右反的情况
- 切换 3D 模式后立即重绘当前帧，无需重新转换

### 界面与交互
- 深色主题：`clam` 风格 + 深灰配色，减少看 3D 时的视觉干扰
- 普通按钮扁平化深灰底，转换 / 导出 / 取消按钮保留橙、绿、红强调色
- `grid` 分层布局：视频区、进度条、按钮栏、视差调节栏、转换进度面板
- 窗口缩放自适应：完整显示（`min` 缩放）+ 模糊背景填充四周
- 拖动窗口时使用快速渲染模式（黑背景），松手后补一次完整模糊渲染
- 全屏切换（F11）：
  - 进入全屏后底栏和视差栏 2 秒无操作自动隐藏，鼠标指针也隐藏
  - 鼠标移动时底栏和视差栏立刻浮现，视频区域自动缩回
  - 退出全屏恢复常显
- 截图：保存当前帧为 `screenshot.jpg`
- 导出 3D 视频：将生成的 3D 文件复制到用户指定路径
- 关闭窗口时彻底释放视频、音频、定时器资源，并强制结束进程

### 性能与稳定性
- 视频播放循环定时器去重，防止叠加导致加速
- 窗口缩放防抖（60ms / 180ms），避免频繁重绘
- 视差 `remap` 坐标网格缓存，避免每帧重建
- 模糊背景降采样到 1/8 再模糊，提升性能
- 转换线程为 daemon 线程，取消事件每帧检查，响应及时

## 安装

1. 克隆仓库：
```bash
git clone https://github.com/Kinen4062/my-project-video.git
cd my-project-video
```

2. 安装依赖：
```bash
pip install opencv-python torch torchvision transformers Pillow numpy ffpyplayer
```

3. 运行播放器：
```bash
python final_player.py
```

首次运行时，程序会自动从 Hugging Face 下载 `Depth-Anything-V2-Small-hf` 模型（约 100MB）。国内网络已设置镜像源 `https://hf-mirror.com`，无需额外配置。

## 核心实现说明

### 2D 转 3D 流程

1. 读取视频帧
2. 使用 Depth-Anything-V2 生成深度图
3. 将深度图归一化到 0~1，乘以最大视差（`max_disparity = 20`）得到偏移量
4. 通过 `cv2.remap` 分别生成左眼（正向偏移）和右眼（反向偏移）画面
5. 左右拼接为 SBS 格式写入输出视频

### 3D 显示模式

- **红蓝 3D**：左眼取蓝色通道，右眼取红色通道，合并为红蓝图像
- **偏振-隔行**：奇数行给左眼，偶数行给右眼
- **偏振-隔列**：奇数列给左眼，偶数列给右眼
- **偏振-棋盘**：按棋盘格交错分配左右眼

### 音频同步

使用 ffpyplayer 的 `MediaPlayer` 解码音频，与视频帧通过定时器粗略同步。暂停 / 继续时同步控制音频播放状态。

> **音频 seek 的坑**：实测发现 `MediaPlayer.seek()` 在暂停状态下调用会直接段错误（SIGSEGV，退出码 139），且 `seek()` 只移动视频流，音频时钟不受影响。因此当前版本在拖动进度条时**不调用** `audio_player.seek()`，而是通过重建 `MediaPlayer` 来同步音频位置。

### 临时文件管理

转换产物使用 `tempfile` + `uuid` 生成唯一文件名，落到系统临时目录，避免污染工作目录。

### 空格键冲突处理

当焦点落在 Button、Entry、Combobox 等控件上时，全局的“空格 = 播放/暂停”会让路，避免一次按键同时触发按钮动作和播放切换。

## 已知限制

- 音频倍速暂未同步（倍速只作用于视频画面）
- 暂不支持播放列表、记忆播放位置、AB 循环、逐帧播放
- 字幕加载未实现
- 硬件解码 / 编码加速未接入
- 3D 输出格式目前只有 SBS
- 拖动进度条时音频同步通过重建 `MediaPlayer` 实现，可能有轻微延迟
